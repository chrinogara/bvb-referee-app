# Circuit logos

Drop the official logo image files here and they appear automatically on the Home hub:

- `cev.png`  — CEV official logo (European Volleyball Confederation)
- `fivb.png` — FIVB official logo (Fédération Internationale de Volleyball)

Recommended: transparent PNG or SVG, roughly 240×240 or wider, square-ish.
If a file is missing, the tile shows a clean text wordmark as fallback.

The Belgian Tour tile uses the national flag (drawn in CSS) — no file needed.
